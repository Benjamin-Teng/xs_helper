# 內建函數（builtin functions / bif）

> 🚧 骨架佔位 — 待蒸餾。
> **來源**：⚠️ bif 為引擎原語，Preset **無**原始碼 → 簽名**唯一來源是 xshelp**（build-time 抓）。
> grammar `keyword.bif` 只確認名字（且 2023 快照已落後，以 xshelp 清單為準）。
> 每條目格式：`名稱 / 簽名 / 參數 / 回傳 / 範例 / 來源`。

## 待蒸餾內容（xshelp 分類）

- [ ] 一般函數（`GENERALFUNC`）：`CurrentBar`、`MaxBarsBack`、`Print`、`Plot[n]`、`OutputField[n]`、`SetBarFreq`、`RaiseRunTimeError`…
- [ ] 時間函數（`TIMEFUNC`）：`CurrentTime`、`Hour`、`Minute`、`TimeToString`…
- [ ] 日期函數：`CurrentDate`、`Year/Month/DayOfWeek`、`DateDiff`、`JulianToDate`…
- [ ] 字串函數：`InStr`、`LeftStr/MidStr/RightStr`、`NumToStr`、`StrToNum`…
- [ ] 數學函數：`AbsValue`、`Round/Floor/Ceiling`、`Power`、`SquareRoot`、`Mod`、`Sign`…
- [ ] 欄位函數：`GetField`、`GetFieldDate`、`GetQuote`…
- [ ] 陣列函數：`Array_Sort`、`Array_Sum`、`Array_Copy`…
- [ ] 交易函數：`SetPosition`、`Buy/Sell/Short/Cover`、`Market`、`AddSpread`、`FilledAvgPrice`…
